# 透析好幫手｜血液透析衛教 3D PWA

給血液透析病人與家屬的衛教 App，使用 three.js 互動場景。

- 乾體重水球人：體重增加 3–5% 紅黃綠燈、每日飲水（前一日尿量＋700 mL）
- 瘻管 3D 手臂：震顫呼呼聲、六項禁止事項
- 就醫警訊：一鍵撥打透析室、119

網址：https://kftseng2oo1.github.io/Hemodialysis/

> 本內容僅供衛教參考，實際以醫療團隊指示為準。

## 🎙 台語／客語真人錄音

1. 錄音人員打開 App → 首頁「朗讀聲音」→「錄音工作台」（或網址加 `#studio`）
2. 選台語或客語，看著華語大字用母語講出來，一點一段；編號（第1點…、共有N點）另外錄
3. 錄完按「匯出全部錄音」，把 zip 傳給開發者
4. 開發者把檔案整理（音量標準化、去頭尾空白）放到 `audio/<nan|hak>/`，並產生 `audio/<lang>/index.json`：
   `{"clips":[{"id":"erList-1","file":"erList-1.m4a"}]}`
5. App 的朗讀聲音選單就會出現「台語（真人錄音）」；還沒錄的段落自動改用華語語音

錄音人員自己的手機，錄好後不用上架就能先試聽。
